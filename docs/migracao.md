# Procedência da separação

[Início](../README.md)

Este repositório foi separado em 20/09/2026 do projeto Gaia, a pedido do mantenedor. A revisão de origem é [`3d7e2d2a4ad80ae7f9d53f9d02cd850a7c8264b2`](https://github.com/Pedronsjaja/gaia-lx225-buslinker/tree/3d7e2d2a4ad80ae7f9d53f9d02cd850a7c8264b2).

Os arquivos da área foram copiados e os links/tutoriais ajustados para a nova organização. O histórico anterior permanece no repositório LX-225, que foi renomeado de `gaia-humanoid-robot`.

Cada arquivo tem uma única área responsável. As alterações futuras devem ser propostas neste repositório; evite manter cópias paralelas em outros projetos. Os testes e ensaios anteriores permanecem identificados pelos links das execuções originais.

O pacote ROS, o cenário, as configurações e a revisão OP3 foram preservados. O workflow foi transferido e o comando de clone agora usa este repositório. A licença MIT continua limitada ao pacote que já a possuía.
